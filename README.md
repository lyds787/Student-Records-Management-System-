# Student-Records-Management-System-
Collaborated on a menu-driven Java application that managed Student, Faculty, and Staff records using a shared  ArrayList collection. 
• Designed a multi-class hierarchy using inheritance, abstraction, encapsulation, polymorphism, and method overriding. 
• Implemented ID validation, duplicate detection, record searching and deletion, GPA and name sorting using 
Comparator, tuition calculations, and text-report generation.
